# SkillCheck — 採用スキルチェックシステム

株式会社LEGAREA 採用選考用の言語スキル判定ツール。
ChallengeBoard / L-1グランプリと同じ構成（バニラJS + Supabase + GitHub Pages）で、**追加コストゼロ**で運用できます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 受験者画面（TOP → 言語一覧 → テスト → 結果） |
| `admin.html` | 管理者画面（受験結果一覧・CSV出力） |
| `sc-core.js` | ロジック（バリデーション・出題生成・採点・本人確認・保存） |
| `sc-questions.js` | 選択式の問題データ（10言語 × 10問から4問出題） |
| `sc-code.js` | 記述式（写経）の問題データ（10言語 × 6問） |
| `config.js` | 設定（Supabase接続・出題数・合格ライン・本人確認方式） |

**6ファイルは常にセットで配置してください。**

## セットアップ

### 1. Supabase
1. 既存プロジェクト、または採用用に新規プロジェクトを作成
2. 別途お渡しするSQLをSQL Editorで実行（テーブル・RLS・権限）
3. 管理者ユーザーを Authentication > Users から追加

### 2. config.js

Supabase の接続情報は**設定済み**です。そのままアップロードできます。

```js
SUPABASE_URL: 'https://yklwkovbphqmiucnmcmu.supabase.co',
SUPABASE_ANON_KEY: 'sb_publishable_...',
```

プロジェクトを変更する場合のみ書き換えてください。
キーは公開前提の publishable key です。anon に SELECT 権限を与えていないため、
Public リポジトリに置いても応募者データは読み出せません。

### 3. GitHub Pages
1. リポジトリ（例 `skill-check`）を作成
2. 5ファイル＋README.mdをアップロード
3. Settings > Pages > Source: `main` / `(root)`
4. 1〜2分待って `https://legarea-d-yukixi.github.io/skill-check/` を確認

**httpsで配信されていないと生体認証もカメラも動きません。**
ローカルの `file://` では動作しないため、GitHub Pages上で確認してください。

## 出題構成

1言語あたり10問。内訳は選択式4問と記述式6問です。

| 形式 | 問数 | 採点 |
|---|---|---|
| 選択式 | 4問 | 提出時に自動採点。結果画面に即時表示 |
| 記述式（写経） | 6問 | 管理画面で担当者が目視採点（10点満点 × 6問） |

記述式は模範解答を解答欄の上に最初から表示し、受験者がそのとおりに入力する形式です。
正しく写せているかの一致率を自動計算しますが、**点数は管理画面で人が付けます**。一致率は参考値です。

受験者の結果画面には選択式の点数のみ表示され、記述式は「担当者が確認します」と案内されます。

## 録画と操作ログ

受験開始から提出までを記録します。録画が本人確認を兼ねるため、顔写真による本人確認はありません。

| 記録するもの | 保存先 |
|---|---|
| 画面（解答エリア）＋カメラ映像を合成した1本の動画 | Supabase Storage（`sc-recordings`） |
| 操作ログ（解答の変更履歴・貼り付け・画面離脱） | `sc_logs` テーブル |

受験前に「受験中の録画に同意します」のチェックが必要です。未チェックでは受験に進めません。

### 模範解答が録画に映らない仕組み

画面録画は `getDisplayMedia` でタブ全体を撮るため、そのままでは模範解答も写ります。
そこで撮影範囲を解答エリア（`#ex-capture`）だけに絞り、模範解答カードをその**外側**に配置しています。

| API | 動作 | 対応 |
|---|---|---|
| Element Capture（`restrictTo`） | 指定要素の配下だけを撮る。重なった要素も除外される | Chrome / Edge 132+ |
| Region Capture（`cropTo`） | 指定要素の矩形で切り抜く | Chrome / Edge 104+ |

**どちらも使えないブラウザでは画面を録画しません**（模範解答が漏れるため）。その場合はカメラのみの録画になります。
共有ダイアログで「画面全体」や「ウィンドウ」を選ばれた場合も範囲を絞れないため、録画を中止して「このタブを選んでください」と案内します。

Safari と Firefox は両APIとも未対応のため、**受験端末は Chrome または Edge（デスクトップ）を推奨します**。

### 使用するカメラ

`navigator.mediaDevices.getUserMedia` で取得します。カメラが2台以上つながっている場合はTOP画面に選択欄が出て、
外付けカメラを指定できます。選んだカメラは次回以降も記憶されます（`localStorage` の `sc_cam`）。

### 容量の目安

720×450・5fps・180kbps で約1.4MB/分。15分の受験で**約20MB**です。
Supabase 無料枠はストレージ1GBなので**およそ50件で上限**に達します。古い録画の定期削除を運用に組み込んでください。
`config.js` の `RECORD_BITRATE` / `RECORD_CANVAS_W` / `RECORD_FPS` で調整できます。

### 管理画面での審査

一覧の「審査する」から、録画の再生・操作ログの再生・記述解答の確認・採点ができます。

## 問題の追加・修正

`sc-questions.js` のみを編集します。

```js
{ q: '問題文',
  choices: ['選択肢1','選択肢2','選択肢3','選択肢4'],
  a: 1,              // 正解のインデックス（0始まり）
  exp: '解説文' },
```

記述式は `sc-code.js` を編集します。

```js
{ t: '問題名',
  task: '修正指示（〜してください。）',
  code: '修正前のコード',
  answer: '模範解答',
  exp: '解説' },
```

言語を追加する場合は `SC_LANGS` に1行足し、`SC_QUESTIONS` と `SC_CODE` に同じ `key` で配列を追加します。
